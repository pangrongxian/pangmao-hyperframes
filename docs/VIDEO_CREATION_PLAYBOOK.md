## 1. 基调法则：不可动摇的美学底座与千变万化的视觉形态

在视频创作中，**“品牌辨识度”依靠统一的美学底座，而“完播率与吸引力”依靠千姿百态的动态特效**。

### 1.1 不可动摇的美学底线（全局统一）
无论制作什么题材的视频，以下 4 个核心视觉锚点保持统一，确保观众一眼看出是你的高质量作品：

| 维度 | 规范标准 | 实现代码与关键参数 |
| :--- | :--- | :--- |
| **画布底色** | 温暖纸质微径向渐变 | `background: radial-gradient(ellipse at 50% 40%, #FCFAF5 0%, #F5F1E6 100%);` |
| **空间参考** | 54px 建筑透光微网格 | 1.5px 线宽，`rgba(185, 170, 150, 0.22)`，赋予空间极高精密感与工整秩序 |
| **出镜 HUD** | 双环正弦呼吸头像 | 110px 悬浮圆环，白边+金边，微动浮沉：`gsap.to(av, { y: -6, yoyo: true, repeat: -1, ease: 'sine.inOut' })` |
| **字幕系统** | 毛玻璃浮空胶囊 | 36px 超大字号，粗体，居中悬浮胶囊：`backdrop-filter: blur(14px); background: rgba(255,255,255,0.94);` |

### 1.2 拒绝千篇一律：视觉形态的无限裂变
**模板是死的，文案是活的。** 每一个分镜的核心视觉主体，必须根据文案的**核心动词和名词**量身定制：
- 文案讲“碰撞/对抗” ➔ **不要用静态卡片**，用红蓝对撞冲击波、裂屏粒子或物理碰撞！
- 文案讲“架构/生态” ➔ **不要用普通列表**，用 3D 卫星公转环、引力知识图谱或白板思维导图！
- 文案讲“性能飙升” ➔ **不要用普通进度条**，用超频仪表盘指针狂飙、能量电涌或数据流喷射！
- 文案讲“底层原理” ➔ **不要用截图**，用深色 IDE 终端自动打字、实时代码 Diff 对比或 AST 语法树展开！

## 2. 分镜解构法：文案到动态视觉的转化工程

拿到一段原始文案，如何将其翻译为具备高冲击力的动态分镜？使用 **“四问分镜拆解法”**：

```mermaid
flowchart LR
    A["文案句子"] --> B["1. 提炼核心概念 (Noun/Verb)"]
    B --> C["2. 匹配视觉隐喻 (Metaphor)"]
    C --> D["3. 选择动效机制 (Animation)"]
    D --> E["4. 配置声效与卡点 (SFX)"]
```

### 步骤清单：
1. **提炼核心动词与情绪**：这段话是让人感到“好奇”、“震撼”、“焦虑”还是“恍然大悟”？
2. **具象化视觉隐喻（Metaphor Mapping）**：
   - 概念：*“全网海量数据筛选”* ➔ 隐喻：漏斗过滤、引力雷达扫描、粒子汇聚。
   - 概念：*“打破传统瓶颈”* ➔ 隐喻：齿轮生锈卡死 vs 超导悬浮飞速穿梭。
   - 概念：*“自动化流水线”* ➔ 隐喻：工厂传送带、机械臂装配、电路板通电点亮。
3. **节奏黄金分割（Pacing Rhythm）**：
   - **前 3 秒（黄金 Hook）**：必须出现强视觉刺激（放大冲击、数字狂跳、疑问气泡爆炸），迅速抓取注意力。
   - **每 4~6 秒（视觉焦点跳跃）**：人类视线在单一静止元素上停留超过 4 秒会疲劳。必须触发新的卡片放大、相机推移或高亮变色。
   - **尾部 3 秒（定格印记）**：严禁黑屏！必须将核心利益点或个人品牌页永久定格。

## 3. 炫酷特效与交互动效兵器库（Visual FX Library）

这里整理了在 GSAP + HyperFrames 体系下可以直接落地的强大动效与特效方案：

### 3.1 卡片与容器类动效

#### ① 3D 陀螺仪透视倾斜卡片（3D Perspective Tilt Card）
- **效果**：卡片在空间中具有景深与厚度，随视线或光标轻微立体倾斜，带有高光反光层。
- **核心实现原理**：
  ```css
  .card-3d-wrap {
    perspective: 1200px;
  }
  .card-3d {
    transform-style: preserve-3d;
    transition: transform 0.4s cubic-bezier(0.2, 0.8, 0.2, 1);
  }
  ```
  ```javascript
  // GSAP 模拟鼠标掠过时的 3D 倾斜与反光
  tl.to(".card-3d", {
    rotationY: 12,
    rotationX: -8,
    boxShadow: "0 30px 60px -10px rgba(45,35,20,0.18)",
    duration: 0.6,
    ease: "power2.out"
  });
  ```

#### ② 便当盒自适应展开（Bento Grid Elastic Expansion）
- **效果**：极具现代科技感的非对称网格（Bento UI），某个模块被讲解时，该网格物理弹簧式挤开其他卡片并放大展开，展示详细内容。
- **适用场景**：多维度功能矩阵、参数对比、套件功能全景。

#### ③ 拟真撕纸便签与手绘荧光笔批注（Sticky Notes & Marker Highlight）
- **效果**：温暖纸质上贴上倾斜 3 度的黄色便利贴（带胶带阴影），随后带有动态笔画的荧光笔横扫划过重点文字。
- **适用场景**：重点警示、反常识金句、避坑总结。
- **核心实现**：
  ```html
  <span class="marker-hl">核心关键点</span>
  ```
  ```css
  .marker-hl {
    background: linear-gradient(104deg, rgba(254,243,199,0) 0.9%, #FEF3C7 2.4%, rgba(254,243,199,0.7) 98%);
    background-size: 0% 100%;
    background-repeat: no-repeat;
    transition: background-size 0.5s ease-out;
  }
  .marker-hl.active {
    background-size: 100% 100%;
  }
  ```

#### ④ 流光流体光环边框（Conic Gradient Border Beam）
- **效果**：在纯白或微暗卡片外圈，一束极具科技感的金色/极光色流光环绕卡片边缘持续飞速流动。
- **适用场景**：全场最强主角卡片、VIP 特权、核心突破点。

### 3.2 科技与数据类动效

#### ① 引力知识图谱与动态拓扑网（Force-Directed Knowledge Graph）
- **效果**：中心节点发散出多个子节点，带有弹簧连线物理震颤，连线上的光斑粒子飞速穿梭。
- **适用场景**：技术生态、知识库网络、技能装载关系。
- **实现手段**：SVG `<path>` 路径 + GSAP `strokeDashoffset` 奔涌动画。

#### ② 3D 环形卫星轨道公转（Orbital Satellite Rotation）
- **效果**：中央为产品主图（如手机或主视口），外围有 3~5 个小圆形功能徽标沿着倾斜椭圆轨道匀速立体公转，穿插至背后时透明度变小并模糊，穿插至胸前时放大发光。
- **适用场景**：生态协同、核心能力环绕、跨平台连接。

#### ③ 动态深色 IDE 终端与代码实时 Diff（Syntax Typing Terminal）
- **效果**：真实 macOS 窗口控制红黄绿三点，光标一字一字敲击指令，实时吐出日志，支持绿色加号新增行与红色减号删除行对比。
- **适用场景**：命令行操作、安装教程、底层代码揭秘。

#### ④ 动态数字心跳翻滚器（Odometer / Rolling Counter）
- **效果**：数字从 0 呈指数级翻滚到 1,514,280，翻滚过程中伴随轻微高频打字音效，到达目标值时数字“怦然心跳”缩放一下（`scale: 1.15` -> `1.0`）并迸发微粒子。
- **适用场景**：用户增长量、下载量、性能提升倍数、跑分超越。

### 3.3 镜头与转场类动效

#### ① 摄像机虚拟景深推拉（Camera Dolly Zoom & Pan）
- **效果**：从宏观全景（如整个操作桌面）瞬间推近到某个具体输入框特写，周围元素出现模拟镜头模糊（`filter: blur(8px)`），讲解完毕后再急速拉远切换全局。
- **适用场景**：由浅入深、局部细节放大、操作演示。

#### ② FLIP 元素无缝空间变形（Seamless Shared Element Morph）
- **效果**：上一个镜头里右侧的一张小功能卡片，在切场时并不消失，而是平滑飞向屏幕中央，形态自然舒展变形为下一幕的全屏主视口！
- **适用场景**：从功能列表平滑切入具体功能实操。

#### ③ 聚光灯黑夜追踪（Spotlight Dim & Tracking）
- **效果**：屏幕整体覆盖 70% 柔和暗色遮罩，仅在一个圆形区域透过强光（带柔和羽化边），强光聚光灯追随光标移动，照亮对应的关键数据。
- **适用场景**：排查问题、发现关键破局点。

## 4. 声画同频法则：听觉母带与情绪曲线设计

一部平庸的视频与一部令人热血沸腾的精品，核心区别往往在于**声音的质感与动作的撞击感**。

```
视觉动作 (Visual Action)   ─────►  精准撞击  ◄─────  音效响应 (Sound SFX)
卡片翻转 / 弹出                     Pop / Click (0.1s 柔脆)
镜头疾驰 / 滑动                     Whoosh (0.3s 空气切削)
数据跳变至最高点                    Ding / Shimmer (金属清脆尾音)
任务确认 / 规约达成                 Check / Thud (低频厚重确定感)
错误打断 / 危机突现                 Glitch / Dull Thud
```

### 自动化音频母带三定律：
1. **人声绝对清晰度**：解说原声必须进行动态压缩限幅（Limiter: -0.95dB，Gain: 2.0~2.5x），平均响度锁死在 **`-18.5 dB` ~ `-19.0 dB`**。
2. **BGM 空间避让法则**：
   - 说话时，BGM 必须缩退至 `-26 dB`（主观听感为隐隐约约的背景铺垫，绝不掩盖辅音细节）。
   - 人声停顿（如抛出悬念的 1 秒静默）时，BGM 可微升 3dB，增强电影叙事呼吸感。
3. **音效超前微调（Pre-delay Adjustment）**：
   - 人脑对视觉先发、听觉后发的反应极为敏感（会觉得“卡顿”）。
   - 音效的爆发峰值点，应比视觉卡片到位的完全静止帧**提前 2 帧（约 0.06 秒）**响起，观众感官上的“打击感”会达到极致。

## 5. 全流程制作 SOP：从一篇文案到一部大片

当你拿到一篇新的文案，按照以下 5 步流水线完成制作：

```text
[Step 1: 文案分段] ──► [Step 2: 匹配特效原型] ──► [Step 3: 编写/派生 HTML] ──► [Step 4: 母带混音] ──► [Step 5: 渲染与QA]
```

### 步骤详细拆解：
- **Step 1：文案按情绪分幕**
  将长文案切分成 4~8 个镜头（Scene），每幕时长控制在 8~20 秒。为每一幕确定一个核心视觉关键词（如：*质疑、冲击、实操、矩阵、顿悟*）。
- **Step 2：从兵器库挑选特效**
  为每一幕选定主体呈现形式：本幕是使用 3D卡片倾斜、便当盒自适应展开，还是终端打字流？
- **Step 3：使用组件库极速拼装场景**
  复用 `core/components.py` 提供的标准化 Header、Avatar HUD、Subtitle Capsule，然后在独立的 `compositions/sceneX.html` 中注入专属 GSAP 时间轴。
- **Step 4：自动化混音与时间戳对齐**
  录制或生成配音音频，在配置中填入音效触发点，运行 `cli.py master-audio` 生成高保真混音音轨。
- **Step 5：快照验证与最终渲染**
  运行 `cli.py snapshot` 抽取关键帧图片快速人工质检，确认无重叠误挡后，运行 `cli.py render` 输出 1080P/30fps 广播级成品。

## 6. 三大经典题材实战脚本拆解范例

### 案例 A：硬核技术深度拆解类
**文案片段**：
> “很多人以为大模型是在‘理解’，其实底层完全是概率矩阵在疯狂计算。比如输入一个词，它会同时激活上千个注意力头……”

**分镜与炫酷特效设计**：
- **视觉主体**：悬浮三维矩阵空间（3D Tensor Cube）。
- **动效演进**：
  1. 初始为一个发光的单卡词元（Token）；
  2. 伴随 `whoosh.wav`，词元瞬间裂变展开为 8x8 立体注意力权重热力方阵；
  3. 光标点击某个特定权重，能量光束连接引力网络，数字从 0.001 飙升至 0.985，伴随能量充能音效；
  4. 画面底部字幕胶囊高亮显示关键词：`概率矩阵`、`注意力头`。

---

### 案例 B：实操技能与工作流推荐类
**文案片段**：
> “不要再手动整理会议纪要了！我把录音丢给 AI，它自动完成了语音转录、要点提炼、并一键同步到了飞书和 Notion。”

**分镜与炫酷特效设计**：
- **视觉主体**：多设备自动化流水线跨屏穿梭（Bento Multi-App Flow）。
- **动效演进**：
  1. 左侧出现一个真实的音频录制波形卡片，微幅律动；
  2. 光标将其“拖拽抛掷”到中间的 AI 处理器中（带有橡皮筋弹跳弹性效果与落盘音效 `tap.wav`）；
  3. AI 芯片发光流光边框高速旋转，0.8 秒后分裂发射出两道金色光轨；
  4. 一道射入右上方飞书卡片（打勾弹出），一道射入右下方 Notion 卡片（自动填充三行要点文字）；
  5. 视觉冲击力拉满，直观展现“自动化 10 倍提效”。

### 案例 C：商业与反常识认知类
**文案片段**：
> “90% 的人都在用大模型搜答案，而真正赚到钱的超级个体，都在把它当‘外包员工’派发任务。”

**分镜与炫酷特效设计**：
- **视觉主体**：撕纸便签分屏天平博弈（Split-Screen Balance & Stamp）。
- **动效演进**：
  1. 屏幕中间竖向劈裂对比，左侧打着灰色标签「普通用户：搜索引擎」，卡片黯淡无光；
  2. 右侧撕纸便利贴猛然盖下一个金色印章「超级个体：智能体外包军团」，伴随重锤敲击音效 `impact.wav`；
  3. 右侧卡片自适应展开，瞬间衍生出 5 个虚拟 Agent 助手小气泡，每个气泡环绕运转并汇报进度；
  4. 强烈戏剧反差建立权威感。
